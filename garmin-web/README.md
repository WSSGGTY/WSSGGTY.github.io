# 日常 · Garmin 健康手记

免费本地网页应用。中国区 Garmin Connect 登录、七天步数、单日睡眠/心率/压力、阶段目标建议、主题与布局调整、JSON 导入导出。

## 运行

安装 Python 3.12 后，在项目目录运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

浏览器打开 http://127.0.0.1:8765。首次点击“连接佳明”，完成登录后可用“刷新数据”复用本机登录状态。验证码在网页提示中输入。

## 使用范围

每个人下载到自己的电脑运行，并登录自己的佳明账号。本版本绑定回环地址，只服务本机浏览器。它没有网站注册、多租户数据库或公网账户隔离，不能直接暴露为公共多用户服务。切换佳明账号会替换该安装目录的本地登录状态。

GitHub Pages 可以展示静态界面并导入个人 JSON，但无法执行这里的 Python 自动取数服务。手机随时访问和公共多人自动同步需要另外部署后端。

## 修改界面与建议

`index.html` 的 CSS 变量控制颜色与圆角，网页内也可切换三种主题和布局密度。`advice()` 根据阶段目标、年龄范围、作息计划和数据生成规则建议。当前没有付费大模型，也没有自由问答。只提供生活方式参考，建议附 CDC/WHO 原始链接。睡眠数据只对应所选日期，不会用其他日期代替缺失数据。

`server.py` 提供本地网页服务，`garmin_daily.py` 复用已验证的取数和报告逻辑。第三方非官方 Garmin 库可能受上游登录流程变化影响。

## 上传 GitHub

只提交源码和 requirements.txt。`.garmin-private` 包含登录凭据，`健康快报` 包含私人健康数据，这些已经在 `.gitignore` 中排除。分享前确认没有把数据文件加入提交。
